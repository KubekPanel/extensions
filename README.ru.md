# Kubek extensions

[English](README.md) · **Русский**

Расширения для [Kubek](https://github.com/KubekPanel): новые страницы панели, виджеты, уведомления,
интеграции. Скачайте `.kubekext` и установите на странице **Расширения**.

Хотите добавить своё? Читайте [CONTRIBUTING.ru.md](CONTRIBUTING.ru.md).

## Индекс

В [`index.json`](https://kubekpanel.github.io/extensions/index.json) лежит всё из этого репо: версии, ссылки на скачивание и sha256. Это для
панели и других программ. Индекс пересобирается на каждый пуш и раз в 6 часов, записи сообщества берутся из
их последнего релиза. Если релиз сломан или GitHub лежит, остаётся прошлая версия. Id из
[`blocklist.json`](blocklist.json) в индекс не попадают, они перечислены в `blocked`, чтобы панель
предупредила тех, у кого они уже стоят.

```sh
bun install
bun run validate            # локальные проверки
bun run validate --remote   # ещё скачать и проверить релизы сообщества
bun run build               # dist/index.json и иконки
```

## От сообщества

Лежат в репо авторов, `.kubekext` скачивается из их релизов. Расширение проверяется один раз при
добавлении, обновления уже нет. Оно работает внутри панели, так что смотрите, что ставите и какие права оно
просит.
