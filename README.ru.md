# Kubek extensions

[English](README.md) · **Русский**

Расширения для [Kubek](https://github.com/KubekPanel): новые страницы панели, виджеты, уведомления,
интеграции. Ставятся во вкладке **Каталог** на странице **Расширения**.

Хотите добавить своё? Читайте [CONTRIBUTING.ru.md](CONTRIBUTING.ru.md).

## Индекс

В [`index.json`](https://kubekpanel.github.io/extensions/index.json) лежит всё из этого репо: версии, ссылки на скачивание и sha256. Это для
панели и других программ. Индекс пересобирается на каждый пуш и раз в 6 часов, пакеты собираются прямо здесь:
официальные из `official/`, от сообщества из коммита, закреплённого в их записи. Если сборка сломалась или GitHub лежит, остаётся прошлая версия. Id из
[`blocklist.json`](blocklist.json) в индекс не попадают, они перечислены в `blocked`, чтобы панель
предупредила тех, у кого они уже стоят.

```sh
bun install
bun run validate            # локальные проверки
bun run validate --remote   # ещё собрать и проверить записи сообщества
bun run build               # dist/index.json, иконки и пакеты
```

## Официальные

От команды Kubek, файлы в [`official/`](official).

- [Туннель](official/tunnel) - Доступ к серверу без проброса портов: Minekube Connect, Pinggy или свой frp

## От сообщества

Лежат в репо авторов, `.kubekext` собирается здесь из проверенного коммита. Каждый новый коммит
проверяется перед публикацией, но проверка может что-то пропустить. Расширение работает внутри панели, так
что смотрите, что ставите и какие права оно просит.
