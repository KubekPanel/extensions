# Туннель

[English](README.md) · **Русский**

Даёт друзьям зайти на сервер, который работает дома, без проброса портов. Рядом с консолью сервера появляется
карточка **Туннель**: нажимаете на неё, выбираете провайдера, включаете туннель и копируете адрес прямо из карточки. Туннель открывается при запуске
сервера и закрывается при остановке.

| Провайдер | Цена | Адрес | Bedrock |
|---|---|---|---|
| [Minekube Connect](https://connect.minekube.com) | бесплатно | `имя.play.minekube.net`, без порта | нет |
| [Pinggy](https://pinggy.io) | бесплатно по часу, на Pro адрес постоянный | `host:port`, на бесплатном меняется каждый час | нет |
| Свой сервер [frp](https://github.com/fatedier/frp) | ваш VPS | `ваш-vps:порт` | да |

## Перед использованием

- **Minekube Connect** запускает [Gate](https://github.com/minekube/gate) перед сервером. Gate сам проверяет
  аккаунты, поэтому серверу нужен `online-mode=false`. У игроков будут офлайн-UUID: на сервере, который работал
  в онлайн-режиме, инвентарь и прогресс начнутся заново. Кто достучится до порта сервера напрямую, например
  из локальной сети, сможет зайти под любым ником.
- **Pinggy** работает через системный `ssh`, он должен быть на машине с панелью (в Docker-образе есть).
  Бесплатный тариф закрывает туннель каждый час, он открывается снова с новым адресом.
- **frp** нужен `frps` на вашем сервере с разрешёнными портами и тем же токеном:
  ```toml
  bindPort = 7000
  auth.method = "token"
  auth.token = "CHANGE_ME"
  allowPorts = [ { single = 25565 }, { single = 19132 } ]
  ```

## Права

- `process:spawn` запускает Gate, frpc или ssh из папки расширения. Панель останавливает их, когда расширение
  выключают
- `http:outbound` при первом использовании скачивает Gate и frpc из их релизов на GitHub. Версии закреплены и
  проверяются по sha256
- `servers:read` и `events:server` узнают порт сервера и следят за запуском и остановкой
- `http:routes` и `storage` хранят настройки по серверам, токены не уходят обратно в браузер

Пользователю нужно право **Open servers to the internet** и доступ к серверу.

## Ограничения

- Один туннель на сервер
- Minekube и Pinggy только для Java
- Нужен Kubek 4.1.3 или новее
